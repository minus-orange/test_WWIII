# `ww3_shel`実行準備チェックリスト

コンパイル成功は、実際の計算ケースが実行可能であることまでは保証しません。
`ww3_shel`実行前に、格子、外力、初期値、出力設定の整合性を確認します。

## 標準的な処理順序

```text
ww3_grid
  → ww3_strt
  → ww3_prnc（必要な外力ごと）
  → ww3_shel
  → ww3_ounf / ww3_ounp
```

## 1. 格子とモデル定義

`ww3_grid.nml`または`ww3_grid.inp`を準備して`ww3_grid`を実行し、
`mod_def.ww3`を作成します。

確認項目:

- 全球格子として経度方向が正しく閉じている
- 水深と海陸マスクの配列サイズが一致している
- 水平格子数が想定値と一致している
- `NK=36`、`NTH=36`が設定されている
- 時間刻み600秒と内部刻み300、300、30秒が設定されている
- ST4、NL1、BT1、UOSTの係数が意図した値になっている

## 2. UOST入力

今回のswitchでは`UOST`が有効です。格子名に対応する以下の入力を確認します。

- `obstructions_local.<gridname>.in`
- `obstructions_shadow.<gridname>.in`

特に確認する項目:

- 格子との対応関係
- 局所透過率・shadow透過率の範囲
- 陸海境界付近の値
- UOSTの係数と全体時間刻みの安定性

UOSTマニュアルでは、安定性の観点から全体時間刻みに注意するよう記載されて
います。高解像度域を含む全球可変格子では、最小格子幅を基準に事前確認します。

## 3. 初期状態

Cold startの場合は`ww3_strt`で`restart.ww3`を作成します。
継続計算の場合は、直前計算のリスタート時刻が今回の開始時刻と一致することを
確認します。

確認項目:

- `restart.ww3`と`mod_def.ww3`が同じ格子・スペクトル構成
- リスタート時刻と`ww3_shel`開始時刻が一致
- Cold start方式が意図した設定

## 4. 外力

必要な外力ごとに`ww3_prnc`などでWW3形式ファイルを作成します。

| 外力 | 代表ファイル |
|---|---|
| 風 | `wind.ww3` |
| 海流 | `current.ww3` |
| 水位 | `level.ww3` |
| 海氷密接度 | `ice.ww3` |

確認項目:

- 外力期間が計算開始から終了までを覆う
- 外力時刻がUTC
- 欠損値・単位・緯度経度の向きが正しい
- 風速成分と海流成分の符号規約が正しい
- 空間格子・補間設定が意図したもの

## 5. `ww3_shel`設定

`ww3_shel.nml`または`ww3_shel.inp`で次を設定します。

- 開始: 2024-01-01 00:00 UTC
- 終了: 2024-02-01 00:00 UTC
- 計算期間: 31日、744時間
- 必要な外力フラグ
- 格子・地点・リスタートの出力時刻
- 出力変数

744時間の本計算前に、短時間のsmoke testを推奨します。

1. 1 MPIプロセス、1～3時間
2. 少数MPIプロセス、24時間
3. 本番MPI構成、短時間
4. 31日本計算

各段階で以下を確認します。

- `log.ww3`に異常終了がない
- NaN、負の波作用量、極端な有義波高がない
- CFLや時間刻みに関する警告がない
- `out_grd.ww3`と`restart*.ww3`が作成される
- MPIプロセス数を変えて結果が許容範囲で一致する

## 6. 実行例

実行ディレクトリに必要ファイルを配置した後:

```sh
mpirun -np 4 /path/to/test_WWIII/build/bin/ww3_shel
```

実際のMPIプロセス数は、海点数、スペクトル数、利用可能メモリ、
I/O性能に基づいて決定します。`DIST`構成では、少なくとも
`W3INIT`内の海点数・スペクトル数に対するプロセス数チェックを通る必要が
あります。

## 7. 後処理

格子出力をNetCDFへ変換:

```sh
/path/to/test_WWIII/build/bin/ww3_ounf
```

地点出力をNetCDFまたは表形式へ変換:

```sh
/path/to/test_WWIII/build/bin/ww3_ounp
```

後処理設定ファイルと出力ファイル名は、使用する`.nml`／`.inp`の指定に
従います。
